# Project governance

SysMender is currently a maintainer-led project. The project owner has final responsibility for repository direction, releases, security-sensitive code, and licensing decisions.

Contributors are welcome to propose changes in issues and pull requests. Design decisions should document the problem, alternatives considered, risks, and the test evidence that would justify acceptance.

Security-impacting changes, elevated-operation workflows, third-party code imports, and release artifacts require explicit maintainer review. Passing CI alone never approves a system-changing feature for release.

As the project grows, ownership and code review responsibilities can be formalized through CODEOWNERS and documented maintainership roles. No additional maintainers or response commitments are implied today.
