# Getting help

SysMender is still under construction. The Windows folder contains a v4.4 source baseline and the Linux edition is not yet released.

For questions about what exists today, begin with the [README](README.md) and [compatibility notes](docs/COMPATIBILITY.md).

- **Reproducible problems:** Use the Bug report issue template. Mention the edition, version, OS, steps, and a sanitized log excerpt.
- **Feature ideas:** Use the Feature request template. Explain the job the tool would help an IT worker complete.
- **Linux distribution support:** Use the Compatibility report template with the output of non-sensitive detection commands only.
- **Security vulnerabilities:** Do not file a public issue. Follow [SECURITY.md](SECURITY.md).

This repository cannot provide emergency system recovery or guarantee a safe fix for production endpoints. If data integrity or availability is at risk, follow your organization's incident and backup procedures.
